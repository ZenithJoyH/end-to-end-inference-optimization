# 20260915-sparse-mla-sq2048-bk32：SQ2048 BK32 特化

- experiment-id：`20260915-sparse-mla-sq2048-bk32`
- 分类：`operator/improve`
- 状态：`retained_then_extended`
- 目标 shape：`SQ2048/HQ4/DQK576/TOPK2048/DV512`

## 方向与改动

为组合 profile 中残留的 SQ2048 通用 sparse MLA 增加 T-Head
`BK32/BH4/4-warps/1-stage` 特化。

## 效果与正确性

单算子 `6381.840 -> 5984.712 us`（`1.066x`），四类 `topk_length` 分布为
`1.069x–1.121x`；数值、SQ1024 fallback、graph capture/replay 通过。
profiler-off A/B/revert 中，P4096/D32/C8/N8 与 P4096/D128/C8/N8 output
throughput 分别提升 `1.218%` 和 `1.291%`，比较回执 `passed`。

## 决策与边界

保留并在下一实验扩展到 `128<=SQ<=2048`。端到端结论仅适用于两个缩减场景。
